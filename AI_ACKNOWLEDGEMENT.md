# Acknowledgement of AI use (UCL Category 2: assistive)

**Draft: the team should edit this to describe exactly how each member used AI, then confirm it
matches the UCL guidance on acknowledging AI.**

This project used Anthropic's Claude (Claude Opus 5.5, via the Claude desktop app, October 2026)
in an assistive role, as permitted for this Category 2 assessment:

- **Background research and brainstorming:** comparing candidate kit concepts and finding suppliers
  and part specifications (springs, bearings, magnets).
- **Design support:** drafting hand calculations, the dynamic model of the rig, and the CAD and
  manufacturing scripts (laser DXF, 3D-print STL and a virtual interference check), which the team
  reviewed, ran and checked against measurements.
- **Software:** drafting the phyphox analysis script and its automated tests.
- **Documentation and planning:** drafting the student lab sheet, video script, presentation
  structure and project timeline.

The team selected the concept, built and tested the prototype, made all design decisions, took all
measurements, and is responsible for the accuracy of everything submitted. AI output was checked by
running the code and tests, comparing with hand calculations, and testing on the physical rig.
